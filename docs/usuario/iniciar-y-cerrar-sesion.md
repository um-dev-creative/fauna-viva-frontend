# Iniciar y cerrar sesión

Para todos los roles: apoderado, recepción, veterinario y administrador de clínica.

## Iniciar sesión

1. Abre el portal de tu clínica. Si no has entrado, verás la pantalla **Iniciar sesión**.
2. Escribe tu **correo electrónico** y tu **contraseña**.
3. Pulsa **Entrar**.

Si tus datos son correctos llegas a la pantalla de inicio. Si recargas la página o cierras y abres la pestaña, sigues dentro: el sistema recuerda tu sesión de forma segura y no vuelve a pedirte la contraseña mientras dure.

## Si no puedes entrar

| Mensaje | Qué hacer |
| --- | --- |
| «Correo o contraseña incorrectos.» | Revisa los datos. Por seguridad el mensaje es el mismo aunque el correo no exista. |
| «Demasiados intentos…» | Espera unos minutos: tras 10 intentos fallidos desde el mismo lugar el acceso se pausa. |
| «No pudimos validar tu acceso…» | Es un problema del servicio, no de tus datos. Inténtalo de nuevo en unos minutos; si sigue, avisa a tu clínica. |

## Cerrar sesión

Pulsa **Cerrar sesión** en la pantalla de inicio. Hazlo siempre que uses un equipo compartido. Tu sesión se cierra en el servidor y volverás a la pantalla de inicio de sesión.

Si tu sesión vence mientras trabajas, el portal te lleva solo a **Iniciar sesión**.
